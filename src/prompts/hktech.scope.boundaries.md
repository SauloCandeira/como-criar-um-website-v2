# HKTech – Scope Boundaries

Este documento define limites claros por fase.
A IA NÃO deve sugerir funcionalidades fora do escopo atual.

## MVP (CURRENT PHASE)

### Allowed
- MyBot Stage 1 (Assistant)
- Event-driven learning (basic)
- Simple recommendations
- Firebase + Firestore only
- Manual admin operations

### Explicitly NOT Allowed
- Autonomous MyBot behavior
- Free-form AI chat
- External LLM calls
- Marketplace reputation algorithms
- Long-term behavioral profiling

## Post-MVP (FUTURE)
- MyBot Stage 2 and 3
- Advanced memory
- Marketplace reputation
- Cloud Run domain separation

Any suggestion outside MVP must be flagged as FUTURE ONLY.
